# Late Start — a free LinkedIn starter

You've been meaning to start posting on LinkedIn for months, maybe years. This takes the hard part out of starting.

An AI interviews you with simple one-line questions about what you do, your wins, your goals and the photos you have. Then it gives you:

- **a posting style** that sounds like you, with your own series name and signature line
- **a 4-week calendar** mixing your stories with things you can teach
- **your first post**, written in full and ready to publish
- **a short checklist** to run before you hit post

It never makes up achievements. Every fact comes from you, and any creative line is marked ⚠️ so you can keep or cut it.

## Use it in any AI chat (easiest)

Open [PROMPT.md](PROMPT.md), copy the prompt into ChatGPT, Gemini or Claude, and answer the questions. That's it.

## Use it as a Claude skill

**Claude.ai or the Claude desktop app**

1. Download `linkedin-starter.zip` from the [latest release](../../releases/latest).
2. Go to **Settings → Capabilities → Skills**, and upload the zip.
3. Start a chat and say: *"Help me start posting on LinkedIn."*

**Claude Code**

Copy the `skills/linkedin-starter` folder into `~/.claude/skills/`, then ask Claude to help you start posting on LinkedIn.

## Why "Late Start"?

I put off posting for about four years. When I finally started, I built this so the next person wouldn't have to wait as long. You're never too late to start.
